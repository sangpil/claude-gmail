무엇을 읽는가

Claude Gmail 은 Google 의 gmail.readonly 권한과 기본 프로필(이메일 주소·이름)만 요청합니다. 메일을 보내거나 지우거나 바꾸지 않습니다.

어디에 두는가

로그인 토큰은 소유자 컴퓨터의 로컬 파일에만 저장됩니다. 이 앱을 위한 서버는 없으며, 메일 데이터를 따로 수집·저장·판매·공유하지 않습니다. 메일 내용은 소유자가 요청할 때 소유자 자신의 AI 도구(Claude Code)로만 전달됩니다.

권한 회수

Google 계정 → 서드 파티 연결에서 언제든지 접근 권한을 회수할 수 있습니다.

Google API 서비스 사용자 데이터 정책

Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API Services User Data Policy 를 따릅니다.

English. Claude Gmail requests only Google's gmail.readonly scope and basic profile information. It never sends, deletes, or modifies mail. OAuth tokens are stored only in local files on the owner's computer; there is no server, and no mail data is collected, stored, sold, or shared. Mail content is passed only to the owner's own AI tool (Claude Code) at the owner's request. Access can be revoked at any time at myaccount.google.com/permissions. Claude Gmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
