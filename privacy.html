무엇을 하는가

Claude Gmail 은 소유자의 Gmail 을 읽고, 소유자가 지시할 때 초안을 만들고 메일을 보냅니다. 이를 위해 기본 프로필(이메일 주소·이름)과 Gmail 권한(gmail.readonly, gmail.compose, gmail.send, 그리고 사용 도구가 함께 요구하는 gmail.modify·gmail.labels)을 요청합니다. 소유자의 설정에서 라벨 변경·보관·삭제 기능은 꺼져 있습니다.

어디에 두는가

로그인 토큰은 소유자 컴퓨터의 로컬 파일에만 저장됩니다. 이 앱을 위한 서버는 없으며, 메일 데이터를 따로 수집·저장·판매·공유하지 않습니다. 메일 내용은 소유자가 요청할 때 소유자 자신의 AI 도구(Claude Code)로만 전달됩니다.

권한 회수

Google 계정 → 서드 파티 연결에서 언제든지 접근 권한을 회수할 수 있습니다.

Google API 서비스 사용자 데이터 정책

Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API Services User Data Policy 를 따릅니다.

English. Claude Gmail reads the owner's Gmail and, only when the owner instructs, creates drafts and sends mail. It requests basic profile information and Gmail scopes (gmail.readonly, gmail.compose, gmail.send, plus gmail.modify and gmail.labels, which the underlying tool requires at this level). Label-changing, archiving and deleting tools are disabled in the owner's configuration. OAuth tokens are stored only in local files on the owner's computer; there is no server, and no mail data is collected, stored, sold, or shared. Mail content is passed only to the owner's own AI tool (Claude Code) at the owner's request. Access can be revoked at any time at myaccount.google.com/permissions. Claude Gmail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
