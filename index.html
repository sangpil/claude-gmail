Claude Gmail

개인용 도구입니다. 저장소 소유자 한 사람이 자기 컴퓨터의 Claude Code 에서 자기 Gmail 을 읽기 전용으로 검색·열람하기 위해 만든 OAuth 클라이언트입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

A personal, single-user tool: an OAuth client that lets the owner read their own Gmail (read-only) from Claude Code on their own computer. It is not offered to the public.
